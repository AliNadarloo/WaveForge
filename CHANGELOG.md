# Changelog

## 1.1.2 — 2026-10-18

- Updated installation, development and numerical validation documentation.
- Windows and source packages can be built directly from the public repository.

## 1.1.1 — 2026-10-18

- Saved figures follow the current Appearance theme and field color maps.
- Live and saved fields use display interpolation; metasurface phase cells remain exact.
- Completed results can be exported with a new appearance without retraining.
- Public source, Windows launcher, installation and development guides, MIT license,
  paper citation and contribution workflow are available together.

## Included research workflows

Configurable ONN/D2NN geometry, dense/FFT Rayleigh–Sommerfeld and angular spectrum
propagation, custom differentiable Python objectives, single/dual scalar channels,
CUDA/CPU training, five optimizers, CST exports, optical logic gates, OAM,
focusing/holography and a four-layer handwritten-digit routing example.
